# Dify 侧运行记录（真实 DeepSeek 模型）

环境：Dify 社区版 **1.18.0**（docker compose）+ **PowerContext 1.4.1**（SQLite）+ DeepSeek 插件 `langgenius/deepseek` 0.0.26，模型 **`deepseek-flash`**。

全部运行都走应用自己的 Service API（`POST /v1/chat-messages`），每次 `conversation_id` 传空字符串（等于新建会话），`user` 即 `sys.user_id`。

使用的就是交付的 [dsl/meow-court.yml](../dsl/meow-court.yml)，没有替换任何节点。
原始返回（query / user / conversation_id / message_id / 完整回复）见 `service-api-runs.json`。
