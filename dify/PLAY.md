# 喵喵法庭 · 怎么玩

> 一句话：你被一只记仇的橘猫传唤上庭，它把你们之间的每一笔恩怨都记在 PowerContext 卷宗里；**关掉窗口重开，它照样记得**，还会翻出你上一次的案底来加刑。

这份文档面向「想上手玩一把」的人。想了解技术实现和部署细节，看 [README.md](README.md)。

---

## 一、先把服务跑起来

游戏需要两个服务（本机演示环境）：

### 1. PowerContext（记忆库）

```bash
# 在 WSL 里执行
POWERCONTEXT_HOME=~/pcdata ~/.local/bin/powercontext server run --host 0.0.0.0 --port 8000
```

看到 `{"status":"ok"}` 就对了：

```bash
curl -s http://127.0.0.1:8000/health/live
```

### 2. Dify（应用平台）

```bash
# 在 WSL 里执行
cd ~/dify/docker && docker compose up -d
```

等 1–2 分钟，容器状态都是 `Up` / `healthy` 后即可访问：

```bash
docker compose ps
```

> 首次启动或重启 WSL 后，Dify 的访问 IP 可能变化，用这条命令拿当前地址：
> `wsl -e hostname -I` → 形如 `http://172.xx.xx.xx/`

## 二、登录

1. 浏览器打开 Dify 地址，例如 `http://172.17.58.240/`
2. 在登录页输入本机管理员账号（本机演示账号见你本地记录；新环境用你自己的 Dify 账号）
3. 进入后点左侧 **工作室**（Studio），在列表里找到 **🐱 喵喵法庭**（CHATFLOW）
4. 点开应用 → 右上角 **预览** 打开对话窗口；或点 **发布** 后用 WebApp 链接直接玩

> 应用已经发布过，`预览` 和在 WebApp 里玩是同一条工作流。

## 三、开始玩

打开对话窗口，你会看到开庭白：

```
⚖️ 喵喵法庭，现在开庭。
我是本庭法官🐱橘座。你和我的每一笔恩怨都会被记进 PowerContext 卷宗，下次开庭照样有效。
· 直接描述你这次干了什么（例：我把猫罐头换成了减肥罐头）
· 输入「查卷宗」查看全部案底
· 「认罪」「辩解」「嫁祸」「撤诉」都行，本庭会酌情加刑
```

两种玩法：

| 你说什么 | 会发生什么 |
| --- | --- |
| 一段「罪行」自述，比如「我把猫罐头换成了减肥罐头」 | **开庭审判**：法官翻卷宗 → 定罪名 → 写判词 → 判刑 → 记进卷宗 |
| 说「查卷宗」（或 案底 / 查卷 / 前科 / 档案 / 记录） | **直接念卷宗**：不调用模型，把 PowerContext 里存的案底原样列出来 |

### 判决书长这样

```markdown
## ⚖️ 第 2 号 · 喵喵法庭开庭

**累犯等级**：★★☆☆☆（前科 1 次）
**案由**：凌晨三点劫猫离键
**被告态度**：认罪——但你这语气不像认错，像在汇报一件好人好事

**判词**：
> 第 1 号案你偷换罐头还嫁祸本猫，本庭念你初犯给了你体面；如今第 2 号……

**刑罚**：判被告上缴 4 罐正经罐头，并把那块键盘拆下来铺进纸箱……
**附加条款**：本猫趴键盘属于办公，被告抱走本猫属于越权执法。
**援引旧案**：第 1 号

—— 法槌落下——退庭。

> 🗄 本案已归档到 PowerContext 卷宗：`art_4a64f74d…`（下次开庭自动翻出）
```

**每一行都有用**：

- **案号**：第几次开庭，= 你的前科数 + 1
- **累犯等级**：0 条案底 ★☆☆☆☆，1–2 条 ★★☆☆☆，3–4 条 ★★★☆☆，5–6 条 ★★★★☆，≥7 条 ★★★★★
- **援引旧案**：法官必须引用前面某一次的案件编号；卷宗为空时它会说「本庭第一次见你」
- **归档回执**：最下面那行 `art_...` 是这条记忆在 PowerContext 里的真实编号

## 四、五句话体验完整玩法

按顺序说这五句，可以完整体验「初犯 → 累犯 → 通缉令 → 查卷宗」：

1. `我把猫罐头换成了减肥罐头，还说是猫自己说要减肥`
   → 第 1 号，★☆☆☆☆，判词说「本庭第一次见你」
2. `我昨晚三点把你从键盘上抱走了`
   → 第 2 号，★★☆☆☆，判词**主动引用第 1 号**
3. **点「新对话」开一个新会话**，再说：`我把你的纸箱扔了，还说是风干的`
   → 第 3 号，★★★☆☆；**新会话里它依然记得前两次**
4. `我把你的猫粮偷吃了，还说是你自己吃腻了`
   → 第 4 号，★★★★☆，判词里开始出现【通缉令】
5. `查卷宗`
   → 直接把 4 条案底原文列出来（这一步不花模型额度）

> 第 3 步是重点：**新会话**里 Dify 的会话变量已被清空，案号和前科次数只能来自 PowerContext，这就是「它真的记得」。

## 五、其它可玩的操作

| 想干什么 | 怎么做 |
| --- | --- |
| 换个身份重新开始 | 开一个无痕窗口（= 新的 Dify 用户），或调 API 时把 `user` 换成新名字 |
| 扮演更离谱的被告 | 「我不认罪，是风干的」「我要反诉你抓伤我」「我申请换法官」——法官会照着卷宗吐槽 |
| 看它记不记得细节 | 先犯一次具体的错（比如「我把你的猫砂盆换成了狗砂盆」），之后说「查卷宗」看原文 |
| 一次给它几条前科 | `python scripts/seed_demo_memory.py --base-url http://127.0.0.1:8000 --user <玩家名>`（写第 1–3 号） |
| 用 API 玩 | 见 README 6.4：`POST /v1/chat-messages`，`user` 就是玩家标识，`conversation_id` 传空 = 新会话 |

## 六、玩不了怎么办

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 回复「⚠️ 卷宗柜打不开」 | Dify 连不上 PowerContext | 确认第 1 步在跑；Dify 容器里执行 `curl $POWERCONTEXT_BASE_URL/health/live` 应返回 `{"status":"ok"}`。Linux/WSL 还要给 `api`/`worker`/`ssrf_proxy` 加 `host.docker.internal` 映射（README 4.2） |
| 报「模型不存在 / Provider does not exist」 | Dify 没配模型 | 设置 → 模型供应商 → 安装并配置 DeepSeek（或任一聊天模型）；再回工作流把 `橘座法官` 节点的模型重选一次 |
| 判词变成一大段纯文本，没有「案由/刑罚」 | 模型没按 JSON 输出 | 说明这次走了降级路径（判决仍会归档）。换更强的模型或降低温度重试 |
| 累犯星级不涨 | 你换了身份（换浏览器/换 user = 新卷宗） | 用「查卷宗」确认条目数；想继续累加就用同一个浏览器 |
| 查卷宗是空的 | 这个身份还没犯过事 | 先说一句罪行，再来查 |

---

## 七、玩完关掉

```bash
# 关 Dify
cd ~/dify/docker && docker compose down

# 关 PowerContext（Ctrl+C，或）
pkill -f "powercontext server run"
```

案底都在 `~/pcdata` 里的 SQLite 中；Dify 的应用配置在 docker volume 里，下次启动还在。
