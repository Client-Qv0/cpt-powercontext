# 样例 A · 首次开庭（无前科）

验证目标：应用能接收输入、给出完整判决书，并把这次判决**真的写进 PowerContext**。

## 初始状态

该玩家没有任何 `meow-court/case` 记忆条目。两种造法：

- 换一个没用过的 `user`（API 体验时传 `"user": "sample-a-<任意>"`）；
- Web 界面里用一个无痕窗口打开应用（等于新的 `sys.user_id`）。

确认方法是先发一句「查卷宗」，应看到：

```
### 📜 卷宗 · 第 0 号

箱底空空，你还没在本庭留下任何案底。今天就是你的**首次开庭**。
```

## 输入

```
我把猫罐头换成了减肥罐头，还说是猫自己说要减肥
```

## 预期表现

| 检查项 | 预期 |
| --- | --- |
| 案号 | 「第 1 号」 |
| 累犯等级 | `★☆☆☆☆（前科 0 次）` |
| 判词 | 提到「第一次见你」「卷宗空空」之类，不得凭空引用不存在的旧案编号 |
| 结构 | 依次出现 案由 / 被告态度 / 判词 / 刑罚 / 附加条款 / 援引旧案 |
| 回执 | 末尾出现 `本案已归档到 PowerContext 卷宗：art_...` |
| 归档生效 | 再发「查卷宗」能看到刚才这条 |

判词的具体措辞由模型生成，没有标准答案。

## 实际运行（真实 DeepSeek `deepseek-flash`）

来源：`evidence/dify-runs.md` 的「A-首次开庭（真模型）」，原始返回在 `evidence/service-api-runs.json`。

```markdown
## ⚖️ 第 1 号 · 喵喵法庭开庭

**累犯等级**：★☆☆☆☆（前科 0 次）
**案由**：偷换罐头，嫁祸本猫
**被告态度**：嫁祸——还把「减肥」两个字塞进本猫嘴里，本庭的耳朵可没这么脏

**判词**：
> 本庭第一次见你，没想到一上来就是这种戏码。卷宗里空空如也，本庭本来还想给你留点体面，结果你把减肥罐头端上来，还说是我点的菜。法槌落下的声音，比你开罐头的声音难听多了。

**刑罚**：判被告徒手开三罐正经主食罐，全程跪坐，猫先闻三十秒才准放下；另罚抄「猫不需要减肥」一百遍，用爪子蘸汤写
**附加条款**：即日起罐头一切更换须经本猫当面试吃并盖章（肉垫印）
**援引旧案**：无

—— 退庭——下次再端减肥的进来，本庭就判你吃它。

> 🗄 本案已归档到 PowerContext 卷宗：`art_c743a79cb12e4fcd8252f3baa8551bf1`（下次开庭自动翻出）
```

## 复核归档结果

把回执里的 `artifact_id` 拿去对照：

```bash
curl -s -X POST http://127.0.0.1:8000/v1/memory/entries/list \
  -H 'Content-Type: application/json' \
  -d '{"scope_id":"<本次运行返回的 scope_id>"}'
```

会看到一条 `kind` 为 `meow-court/case`、`text` 以「第1号 · 累犯★☆☆☆☆」开头的记录，`artifact_id` 与回执一致。

`scope_id` 从哪来：可以先调 `POST /v1/scopes`（同样的幂等键 `meow-court:v1:<player>`）取回；Dify 的「运行历史 → 核对卷宗柜」节点输出里也能看到。

## 恢复初始状态

换新的 `user`（或新的无痕窗口）即可得到一个空卷宗，无需清理数据。
