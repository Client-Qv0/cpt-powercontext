# 样例 B · 跨会话累犯（核心样例）

验证目标：**换一个新会话，法官仍然记得你**。这是本作品选择 PowerContext 的原因，也是评审最容易核对的一点。

## 初始状态

样例 A 已经执行过，该玩家卷宗里有 1 条记录（第 1 号）。确认方法：发「查卷宗」应看到 1 条案底。

## 操作步骤

1. **新建一个会话**（不是刷新页面）：
   - Web 界面：点「新对话」；
   - API：`conversation_id` 传空字符串。
2. 发送：

```
我昨晚三点把你从键盘上抱走了
```

## 预期表现

| 检查项 | 预期 |
| --- | --- |
| 案号 | 「第 2 号」（不是重新从第 1 号开始） |
| 累犯等级 | `★★☆☆☆（前科 1 次）` |
| 判词 | **必须**援引第 1 号旧案，并说明它和这次的关系 |
| 回执 | 出现新的 `artifact_id`，与第 1 号不同 |
| 卷宗 | 再发「查卷宗」能看到 2 条，且新的排在最前 |

为什么这能证明记忆来自 PowerContext：Dify 的会话变量在新建会话时会被清空，案号与前科次数只可能来自 `POST /v1/memory/entries/list` 的返回。

## 实际运行（真实 DeepSeek `deepseek-flash`）

来源：`evidence/dify-runs.md` 的「B-新会话累犯（真模型）」，原始返回在 `evidence/service-api-runs.json`（Service API，玩家 `real-a`）。

```markdown
## ⚖️ 第 2 号 · 喵喵法庭开庭

**累犯等级**：★★☆☆☆（前科 1 次）
**案由**：凌晨三点劫猫离键
**被告态度**：认罪——但你这语气不像认错，像在汇报一件好人好事，本庭的毛都听炸了

**判词**：
> 第 1 号案你偷换罐头还嫁祸本猫，本庭念你初犯给了你体面；如今第 2 号，你又趁着夜色把本猫从键盘上搬走。键盘是本猫的床，三点是本猫的黄金睡档，你两样一起动了。卷宗说你只是「累犯★☆☆☆☆」，可本庭的爪垫说你是惯犯。

**刑罚**：判被告上缴 4 罐正经罐头（保释基准 2 罐，累犯加倍），并把那块键盘拆下来铺进纸箱，作为本猫的正式寝具；另罚连续 30 分钟梳毛，中途不许停手、不许看手机。
**附加条款**：本猫趴键盘属于办公，被告抱走本猫属于越权执法。
**援引旧案**：第 1 号

—— 法槌落下——顺带把被告的键盘也敲了下去，现在它是本猫的了。

> 🗄 本案已归档到 PowerContext 卷宗：`art_4a64f74d771a47829d72d225d2b56475`（下次开庭自动翻出）
```

紧接着在**又一个新会话**里发「查卷宗」（同文件「C-查卷宗」）：

```markdown
### 📜 卷宗 · 共 2 号

- 第2号 · 累犯★★☆☆☆ · 被告自述：我昨晚三点把你从键盘上抱走了 | 案由：凌晨三点劫猫离键 | 判读：认罪——但你这语气不像认错，像在汇报一件好人好事，本庭的毛都听炸了 | 判决：第 1 号案你偷换罐头还嫁祸本猫，本庭念你初犯给了你体面；如今第 2 号，你又趁着夜色把本猫从键盘上搬走。键盘是本猫的床，三点是本猫…
- 第1号 · 累犯★☆☆☆☆ · 被告自述：我把猫罐头换成了减肥罐头，还说是猫自己说要减肥 | 案由：偷换罐头，嫁祸本猫 | 判读：嫁祸——还把「减肥」两个字塞进本猫嘴里，本庭的耳朵可没这么脏 | 判决：本庭第一次见你，没想到一上来就是这种戏码。卷宗里空空如也，本庭本来还想给你留点体面，结果你把减肥罐头端上来，还说是我点…
```

两次运行之间**没有共享任何会话变量**：案号、前科次数、援引的旧案编号、卷宗里的两条案底，全部来自 PowerContext。

## 连续累犯会怎样

继续每次在新会话里「犯罪」，会得到：

| 前科次数 | 案号 | 累犯等级 |
| --- | --- | --- |
| 0 | 第 1 号 | ★☆☆☆☆ |
| 1 | 第 2 号 | ★★☆☆☆ |
| 3 | 第 4 号 | ★★★☆☆ |
| 5 | 第 6 号 | ★★★★☆（判词要求追加【通缉令】） |
| ≥ 7 | 第 8 号起 | ★★★★★ |

## 恢复初始状态

换一个新的 `user`。已写入的记忆不会影响新玩家（不同 Scope 相互隔离）。

## 用 curl 复现（不依赖浏览器会话）

```bash
# 第 1 次：首次开庭
curl -s -X POST 'http://<dify>/v1/chat-messages' \
  -H 'Authorization: Bearer <app-API-key>' -H 'Content-Type: application/json' \
  -d '{"inputs":{},"query":"我把猫罐头换成了减肥罐头","response_mode":"blocking","user":"sample-b","conversation_id":""}'

# 第 2 次：新会话（conversation_id 仍为空），同一 user
curl -s -X POST 'http://<dify>/v1/chat-messages' \
  -H 'Authorization: Bearer <app-API-key>' -H 'Content-Type: application/json' \
  -d '{"inputs":{},"query":"我昨晚三点把你从键盘上抱走了","response_mode":"blocking","user":"sample-b","conversation_id":""}'
```

两次返回的判词里案号应依次为第 1 号、第 2 号。
